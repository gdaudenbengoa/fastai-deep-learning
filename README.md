# Fast.ai + Deep Learning

Proyecto personal para aprender machine learning y deep learning mediante el curso Practical Deep Learning for Coders de fast.ai.

## Objetivos

- Aprender machine learning y deep learning.
- Trabajar con PyTorch.
- Practicar Git y GitHub.
- Documentar el proceso de aprendizaje.
- Aplicar lo aprendido a datos climáticos/oceanográficos.

## Curso

[Practical Deep Learning for Coders](https://course.fast.ai/)
